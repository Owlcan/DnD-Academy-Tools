Character Builder Help

This tool helps you create characters for the Darkling Depths adventure. Follow these steps:

  1. Basic Info: Enter your character's name, race, class, and level.
  2. Attributes: Set your character's six main attributes (Strength, Dexterity, etc.).
  3. Equipment: Choose weapons and armor for your character.
  4. Spells: If your character is a spellcaster, select their known spells.
  5. Complete: Review your character and export it as JSON or a URL.

To import your character into the game, copy the URL or download the JSON file and use the import feature in the game.
